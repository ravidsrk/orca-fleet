=== VERIFY HELP ===
usage: verify.py [-h] --manifest MANIFEST [--contract-source CONTRACT_SOURCE]
                 [--contract-digest CONTRACT_DIGEST] [--repo REPO]
                 [--execute-nc] [--base BASE] [--symbol SYMBOL]
                 [--unit-class UNIT_CLASS] [--no-gh]
                 [--lighting {dark-eligible,lit}]
                 [--dispatch-record DISPATCH_RECORD]
                 [--dispatch-pubkey DISPATCH_PUBKEY]

Independent evidence-manifest verifier.

options:
  -h, --help            show this help message and exit
  --manifest MANIFEST
  --contract-source CONTRACT_SOURCE
                        AUTHORITATIVE frozen contract (path@ref), from the
                        dispatch record — not the manifest
  --contract-digest CONTRACT_DIGEST
                        AUTHORITATIVE sha256 of the frozen contract
  --repo REPO           owner/name for the review lookup (default: infer from
                        origin)
  --execute-nc          request NC replay (currently fail-closed; not
                        implemented)
  --base BASE           integration base branch (for ancestry)
  --symbol SYMBOL       a unit symbol to grep on the base
  --unit-class UNIT_CLASS
                        unit class from the dispatch record (mutation|report-
                        only|planning); missing/unknown => mutation (fail-
                        safe, with a NOTE) — validated in code, not by
                        argparse, so an unknown value cannot wedge the gate
                        (#178)
  --no-gh               offline/no-gh lane (merge-serialization.md): review is
                        a local reviewer artifact at head_sha, coordinator-
                        attested — set by the coordinator, not the worker
  --lighting {dark-eligible,lit}
                        unit lighting from the dispatch record (lit|dark-
                        eligible); dark-eligible waives the independent-review
                        requirement — set by the coordinator, not the worker
  --dispatch-record DISPATCH_RECORD
                        coordinator-signed dispatch record (path or path@ref)
                        binding contract-digest/unit-class/lighting — makes
                        the native hook path sound (#135)
  --dispatch-pubkey DISPATCH_PUBKEY
                        repo-pinned coordinator public key (path or path@ref)
                        that verifies --dispatch-record; a committed pubkey is
                        one the worker cannot swap
